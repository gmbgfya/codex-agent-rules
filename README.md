# codex-agent-rules

一份中文全局 [AGENTS.md](AGENTS.md)，用来减少 Codex 的防御性输出和防御性写作。希望它在聊天里直接回答问题，在报告里把结果写准确，只在某个限制会影响你的决定时提醒你。

比如你问“这次测了什么？”，一句“Windows 上的 38 项单元测试全部通过”就说清了范围和结果。如果你问的是“Android 版今天能发吗？”，真机登录还没测就成了关键信息，应当直接告诉你。两次回答可以依据同一份测试记录，重点随你的问题改变。

这份文件也约定 Codex 怎样做事：普通任务直接完成，修改前先分清工作树里哪些改动属于本次任务，按影响范围验证。复用已有测试结果时注明来源；需要你决定时，把具体的取舍讲清楚。

## 使用

打开 [AGENTS.md](AGENTS.md)，按需要选一个位置：

- **用作个人默认规则：** 默认配置下，文件放在 `~/.codex/AGENTS.md`（Windows：`%USERPROFILE%\.codex\AGENTS.md`）。如果已经有这份文件，先对照内容，只合并想采用的条款。
- **只在一个项目里试用：** 将所需条款合并进项目根目录的 `AGENTS.md`。

想先试试文风，只采用「沟通与交付」一节就够了。
